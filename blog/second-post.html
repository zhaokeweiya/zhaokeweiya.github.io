如何快速搭建个人网站

很多朋友想拥有自己的网站，但总觉得很难。其实搭建一个静态的个人网站， 比你想象中要简单得多——不需要服务器，不需要数据库，更不需要花一分钱。

你需要准备什么

  • 一台电脑，装了任意一种编辑器（如 VS Code）
  • 一个免费的 GitHub 账号
  • 一点点好奇心

第一步：创建项目

新建一个文件夹，在里面创建三个文件： index.html、style.css 和 main.js。这分别是网页的结构、样式和交互。 

my-site/
├── index.html   # 网页内容
├── css/
│   └── style.css # 网页样式
└── js/
    └── main.js  # 网页交互

第二步：编写内容

用 HTML 写好你的文字和图片，用 CSS 让它变得好看，再用一点 JavaScript 添加交互效果， 比如菜单按钮、返回顶部。把项目放到浏览器里打开，网站就完成了。

📌 提示：双击 index.html 文件即可在浏览器中预览， 无需任何安装。

第三步：部署上线

把项目推到 GitHub 仓库，再开启 GitHub Pages，就会得到一个类似 你的用户名.github.io 的免费网址，所有人都能访问。 还可以再买一个专属域名，比如 你的名字.com。

总结

搭建网站的本质，就是"写好内容 + 部署出去"。技术只是手段，内容才是核心。 现在就动手吧，第一步就是新建一个 index.html 文件。

种一棵树最好的时间是十年前，其次是现在。
