如何快速搭建个人网站

很多朋友想拥有自己的网站，但总觉得很难。其实搭建一个静态的个人网站，比你想象中要简单得多——不需要服务器、数据库，更不需要花一分钱。

你用到的技术

这套网站用到的都是最基础的技术：

  • HTML：网页内容的结构
  • CSS：网页的样式
  • JavaScript：网页的交互
  • Markdown：写文章更方便的方式

部署到 GitHub Pages

把代码推到 GitHub 仓库，开启 GitHub Pages，就会得到一个免费网址，所有人都能访问。

git add -A
git commit -m "更新"
git push

总结

种一棵树最好的时间是十年前，其次是现在。
